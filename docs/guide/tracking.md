# Application Tracking

![Job detail with status dropdown and history](/screenshots/status-tracking.png)

Track every job application through its full lifecycle.

## Statuses

Each job moves through a defined status workflow:

| Status           | Description                               |
| ---------------- | ----------------------------------------- |
| **New**          | Unreviewed — just been found              |
| **Saved**        | Worth coming back to                      |
| **Applied**      | Application submitted                     |
| **Phone Screen** | Phone/video screen scheduled or completed |
| **Interview**    | Full interview in progress                |
| **Offer**        | Offer received                            |
| **Accepted**     | Position accepted                         |
| **Archived**     | No longer pursuing (hidden by default)    |

## Updating Status

1. Open a job from your results.
2. Use the status dropdown in the job detail header.
3. Optionally add a **note** with the update (e.g., "applied via company website, used tailored resume").
4. Click **Update**.

Each status change is recorded in the **Status History** with a timestamp. You can view the full history for any job.

## Notes

Add freeform notes to any job — meeting notes, follow-up reminders, contact information. Notes are independent from status updates and can be edited at any time.

## Archiving

When you're no longer pursuing a job, archive it. Archived jobs are hidden by default. Toggle **Show Archived** in the results view to see or restore them.

## Valid Transitions

The status dropdown only shows valid next statuses. For example, you can't go directly from "New" to "Offer" — the progression is intentional and reflects real-world hiring pipelines.
