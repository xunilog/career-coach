# Export & Apply

Export your tailored documents and submit applications.

## Export to PDF

1. Open the adapted resume or cover letter for a job.
2. Click **Export PDF**.
3. The document is saved to your file system with a filename convention: `Resume-<Company>-<JobTitle>.pdf` or `CoverLetter-<Company>-<JobTitle>.pdf`.

## Copy to Clipboard

Click **Copy** to copy the full document text to your clipboard. Useful for pasting into application forms directly.

## Open Apply URL

If the job listing includes an application URL, click **Open Apply URL** to open it in your system browser. Some jobs link directly to an external application page.

If no apply URL is available, the button is disabled — you'll need to search for the company's careers page manually.

## Filename Convention

All exports follow the pattern:

```
<DocumentType>-<Company>-<JobTitle>.pdf
```

For example:

- `Resume-AcmeCorp-StaffEngineer.pdf`
- `CoverLetter-StartupInc-SeniorPM.pdf`

This makes it easy to organize multiple tailored documents in your file system.
