# Screenshots

Current images are **grey placeholder PNGs**. Replace them with real screenshots.

## To capture

1. Launch the app: `npm run tauri dev`
2. Use macOS `Cmd+Shift+4` (press Space for window capture)
3. Save to this directory, overwriting the placeholder

- Window-only (no desktop background)
- Max 1200px wide for docs
